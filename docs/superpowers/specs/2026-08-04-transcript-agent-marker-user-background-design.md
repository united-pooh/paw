# Transcript 消息标识与用户消息视觉设计规格

日期：2026-08-04
状态：已确认，待实现

## 1. 目标

移除 transcript 中独立的 `you >` 与 `agent >` 标题行：

- Agent 文本输出使用 `✦` 作为醒目标记；
- `✦` 位于 transcript 左边框外，紧贴左边框；
- `✦` 与 Agent 回答第一行处于同一行，且不参与正文宽度计算；
- 用户消息不显示符号，通过整行背景色与粗体区分。

本规格只描述视觉和布局契约，不改变 transcript 数据模型、消息顺序、Markdown 解析、工具调用分组或流式状态机。

## 2. 目标视觉

### Agent

```text
✦  模型回答第一行
   模型回答第二行，正文保持原有起始位置。
   模型回答第三行。
```

规则：

1. 每条有可见正文的 Agent 消息只显示一个 `✦`。
2. `✦` 只显示在第一行；后续行不重复。
3. `✦` 在 transcript 内容区域外、左边框外侧，并与左边框保持紧贴关系。
4. Agent 正文的首行和续行使用相同的正文布局，不因 `✦` 减少可用宽度。
5. 空消息、尚无可见流式内容的消息不显示孤立 `✦`。
6. Agent 的 Markdown、代码块、引用、ANSI 清理和工具引用渲染保持现状。

### 用户

```text
┌──────────────────────────────────────────────────────────────┐
│  用户输入的第一行                                             │
│  用户输入的第二行                                             │
└──────────────────────────────────────────────────────────────┘
```

规则：

1. 移除 `you >` 标题行。
2. 用户消息内容区域每一行使用连续的整行背景色，从 transcript 内容左边界铺到右边界。
3. 用户正文使用粗体。
4. 背景不扩展到 transcript 外部，不覆盖 Agent 的 `✦` 区域。
5. 用户消息原有颜色语义优先复用；如需新增样式，只新增用户消息背景/粗体样式，不改变标签、工具、错误和 Markdown 颜色。
6. 多行消息保持相同背景和粗体，不产生逐行气泡边界。

## 3. 消息和工具关系

工具调用仍使用既有工具标题、状态、详情和分组布局，不显示 `✦`：

```text
✦  我先运行测试。

│  工具调用
│  go test ./...
│  ✓ 完成
```

Agent 文本、工具调用、下一条用户消息之间沿用现有间距和滚动行为。

## 4. 宽度、边框与 ANSI

- `✦` 不计入 transcript 正文宽度、Markdown 渲染宽度或换行宽度。
- 用户背景只覆盖 transcript 内容区域，不能越过面板边框。
- 必须使用终端显示宽度计算，兼容 Unicode、ANSI 和窄窗口。
- Agent 第一行和后续行的正文宽度规则一致。
- 不允许因移除标签或添加标记造成水平溢出、截断异常或滚动高度错误。
- 现有主题切换、背景恢复和 Lip Gloss 样式重置行为必须保持有效。

## 5. 流式、缓存和恢复

- Agent 流式输出从空内容变为首个可见字符时，`✦` 与首行同步出现。
- 流式刷新不得重复追加 `✦`。
- transcript 渲染缓存 key 必须区分新的标记/用户背景渲染模式，不能复用旧的 `you >`/`agent >` 布局缓存。
- 会话恢复后的历史 Agent、用户消息使用同样规则。
- 仅工具输出或不可见空白不应产生 Agent 标记。

## 6. 实现边界

建议优先调整统一的 entry 渲染入口，而不是在各调用方分别拼接：

- Agent：将外部 gutter 标记与正文渲染分离；
- User：在正文渲染结果上应用整行背景和粗体，并保留原有宽度；
- 标签渲染函数不再输出 `you >`/`agent >`；
- 工具、思考、系统和错误消息沿用现有标签，除非现有渲染入口要求兼容处理；
- 更新 transcript 宽度、滚动高度、缓存签名和视图拼接测试。

## 7. 验收标准

必须覆盖以下回归场景：

- Agent 单行：有一个 `✦`，无 `agent >`。
- Agent 多行：只有第一行有 `✦`，续行不重复，正文宽度不变。
- 用户单行/多行：无 `you >`，每行整行背景且粗体。
- Agent 空消息和流式首字节：不显示孤立标记，首个可见内容出现时显示标记。
- 工具调用：不出现 `✦`，原有详情、状态和分组不变。
- 窄窗口、Unicode、ANSI 和主题切换。
- transcript 滚动、缓存刷新、会话恢复。
- 全量 `go test ./...`、`go vet ./...`、`gofmt -l internal/ cmd/` 与 `git diff --check` 通过。

## 8. 非目标

- 不修改 transcript 中用户/Agent 的数据类型或持久化格式。
- 不修改工具 turn/session 生命周期。
- 不改变 Markdown 语义、代码高亮规则或工具详情内容。
- 不为每个 Agent 段落、工具调用或换行重复显示 `✦`。
