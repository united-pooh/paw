# Code Block Title on Border — 设计规格

**日期：** 2026-07-28
**范围：** `internal/ui/bubble` Markdown 代码块渲染
**状态：** 已批准

## 背景

当前 fenced code block 的语言标签单独占用一行：

~~~text
go
┌────────────────────┐
│ fmt.Println("hi")  │
└────────────────────┘
~~~

这会额外消耗一行终端高度。目标是把语言标签移动到代码块顶边中央，让标签与边框合并，同时保留代码内容、颜色、换行和终端宽度处理。

## 已确认的用户决策

- 使用“顶边中间断开”的布局。
- 所有有语言标签的代码块都采用该布局，不只处理 `text`。
- 标题必须严格居中。
- 标题左右各保留一个可见空格。
- 空格和标题文字共享同一块背景色。
- 标题背景采用现有 `Signal Cyan` 颜色方向。
- 没有语言标签的代码块不显示默认的 `code` 标题。
- 目标是减少一行高度，不允许通过换行或溢出来实现。

## 方案

在现有纯函数 Markdown 渲染路径中直接生成带标签的顶边。保留 `renderCodeBlock`、`renderCodeBlockPanel` 和现有代码正文渲染的职责边界，不引入新的状态、数据格式或 Markdown 解析模型。

渲染结果示意：

~~~text
──────────  text  ──────────
│ feat(agent): ✨ 增强模型容错与终端交互体验 │
└──────────────────────────────────────────┘
~~~

其中标题实际是一个带背景色的胶囊：

~~~text
[空格][语言标签][空格]
~~~

### 渲染流程

1. `renderCodeBlock` 清理语言字符串。
2. 语言字符串非空时，将其作为顶边标题传给代码块面板；语言字符串为空时传递空标题。
3. 代码块宽度同时根据代码正文和标题胶囊计算。
4. 面板顶边计算左右边线，使标题位于水平中心，左右长度相差最多一个终端 cell。
5. 代码正文继续使用现有的内容宽度、换行、行数限制和边框渲染逻辑。

## 视觉与样式

新增一个代码块标题样式，放在 `internal/ui/bubble/styles.go`：

- 前景色：现有终端背景色，确保在亮色 Signal Cyan 背景上有足够对比度。
- 背景色：现有 `colorSignal`，当前值为 `#76D5E8`。
- 字重：粗体。
- 不使用 Lipgloss padding 隐式制造空格；由渲染器明确渲染一个前置空格和一个后置空格，保证显示宽度和背景范围可测试。

边框继续使用现有 `markdownCodeBlockBorderStyle`。标题胶囊本身覆盖顶边中间的一段边线，两侧边线保持同一边框样式。

## 宽度规则

设：

- `bodyWidth` 为代码内容所需宽度加现有边框内边距；
- `labelWidth` 为语言标签的终端 cell 宽度；
- `chipWidth = labelWidth + 2`，其中 `2` 是标题两侧的可见空格。

带标题时，代码块至少需要容纳：左右边框、标题胶囊，以及标题两侧各一段边线。因此标题布局的最低宽度为 `labelWidth + 6`。最终宽度取现有可用宽度上限内的最大必要宽度：

~~~text
max(bodyWidth, labelWidth + 6, minimumPanelWidth)
~~~

顶边剩余边线宽度在左右平均分配；出现奇数 cell 时允许一侧多一个 cell，不视为视觉偏移。

如果可用宽度不足以放下完整标题：

1. 按终端 cell 宽度截断语言标签；
2. 保留标题胶囊的一对空格和至少一侧可见边线；
3. 如果连一个字符和必要边线都无法容纳，则回退到无标题顶边；
4. 绝不让标题换成新行，也不允许渲染结果超过内容宽度。

无语言标签时使用普通顶边，不计算标题宽度，也不渲染 `code` 默认标签。

## 不在范围内

- 不改变 Markdown 原文和会话存储内容。
- 不改变 fenced code block 的解析规则。
- 不新增语法以支持标题别名、文件名或额外元数据。
- 不改变代码正文的语法高亮、换行、Unicode 宽度或最大行数限制。
- 不重构整个 Markdown 渲染器。

## 测试与验收

### 单元测试

在 `internal/ui/bubble` 中更新现有代码块测试，并补充以下覆盖：

- 语言标签位于顶边而不是独立行。
- 标签包含前后各一个空格，且 ANSI 背景样式覆盖这两个空格和标签文字。
- 顶边标题左右边线长度相差最多一个 cell。
- 无语言标签时不出现 `code` 或其他独立标签行。
- 长语言标签会截断，不造成超宽或额外换行。
- 极窄宽度可以安全回退到无标题顶边。
- 现有中文、emoji、嵌套 Markdown fence、代码行数限制和正文换行测试继续通过。

### 验证命令

~~~sh
go test ./internal/ui/bubble -count=1
go test ./... -count=1
NO_COLOR=1 go test ./internal/ui/bubble -count=1
git diff --check
~~~

### 手动验收

通过真实入口运行 TUI：

~~~sh
go run cmd/agent/main.go
~~~

在宽度约 80、40、20 的终端中分别观察：

- 标题是否保持在代码块顶边中央；
- Signal Cyan 背景是否覆盖标题两侧空格和文字；
- 代码块是否比旧布局少一行；
- 长标签和中文标签是否保持边界内；
- 无语言代码块是否没有额外标题。

## 成功标准

当所有单元测试和验证命令通过，并且真实 TUI 在宽、中、窄终端中满足上述手动验收条件时，本设计视为实现完成。
