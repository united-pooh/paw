# Literature survey

- CRDR (EMNLP 2022): explicit query rewriting and contextualized dense retrieval jointly improve conversational retrieval. https://aclanthology.org/2022.emnlp-main.311/
- AdaCQR (COLING 2025): align sparse and dense retrieval during query reformulation. https://aclanthology.org/2025.coling-main.515/
- Query2doc (EMNLP 2023): pseudo-document query expansion improves sparse and dense retrieval. https://aclanthology.org/2023.emnlp-main.585/
- BGE-M3 model card: recommends hybrid retrieval followed by reranking. https://huggingface.co/BAAI/bge-m3
