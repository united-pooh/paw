## ⚠️ 一、勘误总表：15 个链接中 6 个是错的

这本书的论文清单质量不错（主题覆盖合理），但 **arXiv 链接的错误率高达 40%**——部分编号张冠李戴，指向了毫不相干的领域（医学影像、无人机、弦论……）。按图索骥的话会浪费大量时间。以下为逐条核验结果：

| # | 书中标题 | 书中编号 | 核验结果 | 实际内容 / 正确替代 |
|---|---------|---------|---------|---------------------|
| 1 | Reinforcement Learning Framework for Quantitative Trading | `arXiv:2411.07585` | ✅ 正确 | RL 框架 + 技术指标区分多空，ICAIF 2024 FM4TS 工作坊 |
| 2 | Deep Reinforcement Learning for Automated Stock Trading | `arXiv:2007.14592` | ❌ **错误** | 实际是无人机 SLAM 地图恢复（CV）。书想引的应是 **FinRL**：`arXiv:2011.09607`（Liu et al. 2020，539 引用，量化 DRL 库鼻祖） |
| 3 | A Survey of Reinforcement Learning Techniques in Finance | `arXiv:2109.04946` | ❌ **错误** | 实际是弱引力猜想（高能物理弦论）。替代：Hambly et al. `arXiv:2112.04553`（463 引用，经典）或 Pippas et al. `arXiv:2408.10932`（2024，评述 167 篇文献） |
| 4 | Multi-Agent Deep RL for Liquidation Strategy | `arXiv:1906.11046` | ✅ 正确 | 把 Almgren-Chriss 扩展为多智能体清仓环境，协作/竞争 reward 设计 |
| 5 | Multi-Agent Reinforcement Learning for Stock Trading | `arXiv:2103.03705` | ❌ **错误** | 实际是 FedDis 脑部病理影像联邦学习。该主题尚无公认权威编号，可用 `arXiv:2103.03705` 邻域的新作：如 TradingGPT（见 #12）或 `arXiv:2412.20138`（Multi-Agents LLM Financial Trading Framework） |
| 6 | Market Making via Reinforcement Learning | `arXiv:1804.04216` | ✅ 正确 | Spooner et al.，AAMAS 2018，tile coding + TD 学习做市，库存风险控制 |

| 8 | Empirical Asset Pricing via Machine Learning | NBER w25398 | ✅ 正确 | Gu-Kelly-Xiu 经典，ML 资产定价标杆（需 NBER 访问，也可找 SSRN 版） |

| 11 | Risk-Sensitive Reinforcement Learning for Trading | `arXiv:2006.05817` | ❌ **错误** | 实际是自动驾驶边缘流数据处理。风险敏感 RL 可参考 `arXiv:1801.08104`（Deep RL for trading with risk 相关）或 FinRL 的风险敏感 reward 实践 |
| 12 | FinGPT: Open-Source Financial LLMs | `arXiv:2306.06031` | ✅ 正确 | IJCAI 2023 FinLLM 研讨会 Best Presentation，AI4Finance 开源 |
| 13 | BloombergGPT: A Large Language Model for Finance | `arXiv:2303.17564` | ✅ 正确 | 50B 参数，363B 金融 token + 345B 通用 token |
| 14 | Large Language Models in Finance: A Survey | `arXiv:2311.10723` | ✅ 正确 | ICAIF-23，含"按预算选方案"决策框架 |
| 15 | FinAgent: Multimodal Foundation Agent | `arXiv:2402.18485` | ✅ 正确 | 多模态（数字+文本+K线）+ 双级反思 + 多样化记忆 |

## 二、精读地图：按主题吃透

### 主题 A：反过拟合与策略评估（最该先读 ⭐⭐⭐⭐⭐）

> 书里必读经典区选了 López de Prado 三篇，这是整张清单的"地基"——**不读这三篇，后面所有论文的结果都不可信**。

- **Pseudo-Mathematics and Financial Charlatanism**（Bailey et al. 2014, AMS Notices）：回测优化器必然在纯随机数据上"发现"高夏普策略；在带记忆效应的金融序列里，过拟合甚至会**主动亏钱**（极端随机模式会被市场"undo"）。配套在线演示：datagrid.lbl.gov/backtest。
- **The Deflated Sharpe Ratio**（Bailey & López de Prado 2014, JPM）：把"试验次数 N、各试验夏普方差、样本长度 T、偏度、峰度"纳入一个统计量，回答"这个夏普是运气吗"。论文自带 Python 代码（Snippet 1）和数值例子——**我们菜二就是把它落地成可运行代码**。
- **Advances in Financial ML**（书，2018）：全书方法论，第 11 章起是反过拟合主力（CSCV、PBO、defense），比单篇论文成体系。

### 主题 B：强化学习与量化交易

| 论文 | 核心思想 | 可借鉴点 |
|------|---------|---------|
| FinRL (`2011.09607`) | DRL 库：环境/代理/应用/基准四大模块 | 工程化范式：统一环境接口 + 多种算法可插拔；state 用技术指标+持仓，reward 用夏普/波动调整 |
| RL Framework (`2411.07585`) | 用技术指标帮 RL 区分多/空动作 | 作者的诚实值得学习："RL 只在回测里成功"是文献普遍问题——**别信回测，信 OOS 与实盘** |
| RL in Finance 综述 (`2112.04553`) | MDP 建模、算法分类（value/policy/model-based） | 快速建立领域坐标系；汉堡王算法选型表 |

### 主题 C：多智能体系统（书的 Part 4 核心）

- **Multi-Agent Liquidation** (`1906.11046`)：把 Almgren-Chriss 最优执行扩展成多智能体环境——**学它怎么把经典模型改造成 RL 环境**，这是最实用的工程技能。
- **TradingGPT** (`2309.03736`)：每个 agent 三层记忆（短期/中期/长期，各配自定义衰减函数）+ **agent 间辩论** + 给 agent 分配"交易性格"（保守/激进）增加决策多样性。对应书中第 10–11 课。
- **FinMem** (`2311.13743`)：工作记忆→情景记忆→长期记忆的自适应层级，**用交易盈亏作为记忆重要性的奖惩信号**（profit/loss 驱动的记忆剪枝），让 agent 记住"赚钱的记忆、忘掉亏钱的噪音"。

### 主题 D：市场微结构与高频

- **Market Making via RL** (`1804.04216`)：高保真 LOB 模拟器 + tile coding 线性值函数 + **把库存风险写进 reward**。做市的核心矛盾就是库存风险 vs 价差收益。
- **Deep LOB Forecasting** (`2403.09267` / DeepLOB `1808.03668`)：CNN/注意力网络直接从 L1-L4 盘口数据预测中价变动方向。注意：这类论文的"预测准确率"≠"可交易 alpha"，中间隔着交易成本与执行——正好对应书中第 18 课。

### 主题 E：因子投资与 ML

- **Gu-Kelly-Xiu** (NBER w25398)：用 NN/树模型预测横截面收益，样本外 R² 从 <0.5% 提到 ~0.4%（月度），**经济收益主要来自波动率择时与分散化**。这是"ML 因子"领域必引的第一篇。
- **Stock Price Prediction** (`2009.10819`)：NIFTY 50 + LSTM + walk-forward。单标的时序预测天花板很低——它的价值在于 walk-forward 验证流程。
- **Deep Portfolio Theory** (`1605.07230`)：Markowitz + 深度分层组合，encode→calibrate→validate→verify 四步。思想大于结果：把组合构建当"表示学习"问题。

### 主题 F：大语言模型与金融（2024-2025 主线）

| 论文 | 一句话 | 对你的意义 |
|------|--------|-----------|
| BloombergGPT (`2303.17564`) | 有钱任性：50B 参数 + 708B token | 结论：**别自己训金融 LLM**，微调/检索更划算 |
| FinGPT (`2306.06031`) | 数据为中心 + LoRA 轻量微调 | 最实用的路线：开源模型 + 自己攒数据 + LoRA |
| LLM in Finance Survey (`2311.10723`) | 零样本→少样本→微调→从零训练 的决策阶梯 | 按你的算力/数据预算选档位 |
| MarketSenseAI (`2401.03737`) | GPT-4 CoT 读 4 类数据出信号，**用解释做校验** | 已上期刊（NC&A 2024），是"LLM 选股"最扎实的实证 |
| FinAgent (`2402.18485`) | 多模态（行情+新闻+K线图）+ 反思 + 记忆检索 | 多模态是 LLM 交易 agent 的下一步；工具调用增强 |
| TradingGPT / FinMem | 分层记忆 + 多智能体辩论 / 盈亏驱动记忆 | 直接对应书中第 11、14 课的架构图 |

## 三、学习路线图（按目的选读）

```
第一步（1 周）：反过拟合地基
  Pseudo-Math → Deflated Sharpe → AFML 第 11-12 章 → 跑我们的菜二代码

第二步（1-2 周）：经典量化
  Gu-Kelly-Xiu（因子 ML）→ Almgren-Chriss（执行，书第 19 课）→
  Market Making via RL（微结构）→ Deep Portfolio Theory（组合）

第三步（2-4 周）：RL / 多智能体
  FinRL（跑通它）→ Multi-Agent Liquidation（环境改造）→
  TradingGPT / FinMem（读架构，画图复述）

第四步（持续）：LLM 应用
  Survey（选型）→ FinGPT（跑 LoRA 微调）→ MarketSenseAI / FinAgent（看实证）
```

**贯穿始终的铁律**（书第 07 课 + 附录 B 的浓缩）：
1. 任何策略报告必须披露：试验次数 N、各试验夏普分布、样本长度 T、偏度峰度——没有这些的夏普一文不值。
2. 回测不是验证，OOS + 实盘小仓位才是。
3. arXiv 论文 40% 的链接可能是错的（笑），引用前逐个核对。
