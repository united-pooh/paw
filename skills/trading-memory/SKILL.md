# Trading Memory — 交易认知记忆

TradeMemory 实现交易 Agent 的认知记忆架构：每笔交易带完整上下文（市场条件、策略、推理、信心）存储，
用 **OWM（结果加权记忆）** 打分召回——优先浮现相似情境下的盈利交易。

> 这不是交易日记，是一套"学习哪些过往经验与当前决策最相关"的记忆系统。

## 三层流水线

```
L1: 原始交易 → L2: 模式发现 → L3: 策略调整
```

- **L1 (Episodic)**：每笔交易原样存储（ground truth）
- **L2 (Patterns)**：从 L1 发现行为模式（处置效应、时段偏差、策略相关性）
- **L3 (Adjustments)**：由 L2 得出具体策略调整（参数/规则/策略退役）

## OWM 5 种记忆类型

| 类型 | 内容 | 何时写 | 何时读 |
|------|------|--------|--------|
| 1. Episodic 情景 | 原始交易事件（标的/方向/进出场/P&L/策略/市场上下文/反思/时间戳） | 每笔交易结束后 | 回忆历史交易 |
| 2. Semantic 语义 | 策略知识库："VolBreakout 在伦敦时段 + ATR>40 表现最佳" | 存交易时自动更新 | 评估策略是否适配当前条件 |
| 3. Procedural 程序 | 行为基线：各策略平均持仓时长、仓位一致性、止损执行率、入场时机精度 | 从交易历史自动计算 | 行为分析、每日复盘 |
| 4. Affective 情感 | 信心水平(0-1)、回撤%、连胜/连亏、风险偏好、tilt 指标 | 每笔交易后 + 每日复盘 | 入场前"我是否上头发了？"、风控检查 |
| 5. Prospective 前瞻 | 活跃交易计划："若 X 突破 Y 且 ATR 确认则做多"（含入场/退出条件、风险参数、过期日） | 创建计划时 | 检查当前行情是否命中任何活跃计划 |

## OWM 召回打分

| 因子 | 权重 | 说明 |
|------|------|------|
| P&L 结果 | 40% | 盈利交易优先，幅度起作用 |
| 上下文相似度 | 30% | 回忆上下文与查询上下文的匹配度 |
| 新近度 | 20% | 近期交易加权（指数衰减） |
| 信心校准 | 10% | 信心与结果一致的交易得分更高 |

**为什么结果加权？** 传统交易日记对所有交易一视同仁。OWM 放大相似情境下成功决策的信号——
如果你在伦敦时段突破交易上赚过 5 次，评估下一次伦敦突破时这些记忆会强烈浮现。

## 工具映射（MCP 化建议）

| 工具 | 用途 |
|------|------|
| `remember_trade` | 完整 OWM 存储：写入全部 5 层记忆 |
| `recall_memories` | OWM 召回：按结果/相似度/新近度/校准打分 |
| `get_behavioral_analysis` | 程序记忆：处置效应比率、持仓时长、Kelly 准则 |
| `get_agent_state` | 情感状态：信心、回撤、连胜/连亏、风险偏好 |
| `create_trading_plan` | 前瞻记忆：入场/退出条件、风险参数 |
| `check_active_plans` | 对当前行情评估活跃计划 |
| `get_strategy_performance` | 按策略聚合：胜率、盈亏比、P&L |
| `get_trade_reflection` | 单笔交易推理深挖 |

## 最佳实践

### 何时记录
- **收盘后**记录，不在持仓中记录
- 含完整市场上下文：时段、波动率、趋势状态
- 诚实写反思：为什么进、预期什么、发生了什么
- **在看到结果前**设定信心（不能事后设）

### 何时召回
- 入场前："我以前遇到过这情况吗？结果如何？"
- 每日复盘："本周交易浮现什么模式？"
- 亏损后："我以前见过这种失败模式吗？"

### 何时不召回
- 不在持仓中为了给亏损找理由而召回
- 不为了确认已做的决定而召回（确认偏差）
- 不过度查询——一天召回 20 次是在拖延，不是在交易

## 常见错误

| 错误 | 后果 | 修复 |
|------|------|------|
| 无上下文记录 | 无法匹配未来情境 | 总是包含时段/波动率/趋势 |
| 看 P&L 后才设信心 | 毁掉校准评分 | 入场时、结果未知前设定 |
| 忽略情感状态 | tilt 交易 → 报复性交易 | 每场交易前查 `get_agent_state` |
| 从不每日复盘 | 行为漂移无法发现 | 每天收盘跑一次复盘 |
| 模拟盘与实盘混记 | 污染绩效指标 | 模拟盘单独打标签或单独库 |

## 数据流

```
交易结束 → remember_trade() → Episodic（原始事件）
                            → Semantic（策略知识更新）
                            → Procedural（行为基线更新）
                            → Affective（信心/连胜更新）
                            → Prospective（检查活跃计划）
    ↓
recall_memories() ← OWM 打分
    ↓
下一次交易决策
```

## 与 quant-mcp 模拟盘配合

模拟盘每笔成交（`paper_*` 工具）自动写入 Episodic 记忆；每日结算后跑 `get_behavioral_analysis`
做行为漂移检查；`check_active_plans` 由盯盘 skill 在开盘前调用，命中则提醒。
